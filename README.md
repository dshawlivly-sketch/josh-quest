# Square & Cube Quest

A 16-bit style adventure quiz where Coach Josh Allen teaches perfect squares and cubes from 1 to 25.
Vanilla HTML/JS, no build step. Installable on a phone home screen and playable offline.

- Play: open `index.html` (or the GitHub Pages site for this repo)
- Landscape phone works best. Add to Home Screen for full-screen app mode.
- When you change any game file, bump `VERSION` in `sw.js` so phones refresh their offline copy.

Fan-made learning game. Not affiliated with the NFL, the Buffalo Bills or Josh Allen.
